Estructura de una página

<!DOCTYPE html>
Indica al navegador que use el modo estándar de HTML.
<html>
Contiene el encabezado y el cuerpo del documento.
<head>
Guarda información sobre la página, como el título de la pestaña.
<body>
Contiene lo que se muestra en la página.

Títulos, párrafos y listas

<h1>
Marca el título principal.
<h2>
Marca un subtítulo dentro del tema principal.
<h3>
Marca un subtítulo dentro de una sección de segundo nivel.
<p>
Agrupa el texto de un párrafo.
<ul>
Crea una lista con viñetas.
<ol>
Crea una lista ordenada, normalmente numerada.
<li>
Marca cada elemento de una lista.

Etiqueta de cierre

La diagonal / va justo después de < e indica dónde termina el elemento.
